About Content Governance Dashboard

Overview

The Content Governance Dashboard is a comprehensive tool designed to manage and track content records efficiently. It provides a user-friendly interface for organizing, filtering, and exporting content governance data.

Key Features

  • Dashboard: View and manage all content records with real-time editing capabilities
  • Date Range Filtering: Filter records by expiry date range to view specific content
  • Data Export: Export filtered or all records as CSV files for further analysis
  • Components Management: Create and maintain a library of reusable UI components
  • Local Storage: Secure data persistence using browser local storage
  • User Authentication: Secure login system to protect sensitive data

How to Use

Dashboard

  • Add new records by clicking "Add Row"
  • Edit records directly in the table cells
  • Filter by date range to find specific records
  • Save data locally using "Save (Local)" button
  • Export filtered records as CSV

Components

  • Add new components using the form at the top
  • View all components in the list below
  • Delete components no longer in use
  • Export components list as CSV

Default Credentials

Username: Admin

Password: admin

Data Storage

All data is stored in your browser's local storage. This means your data persists across browser sessions but is unique to this browser and device. Be cautious when clearing browser data, as it will remove all stored information.
